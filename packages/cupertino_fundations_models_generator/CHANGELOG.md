## 1.8.0

Prepared locally; not published. First optional generator companion for core 1.8.0.

- Emit deterministic standalone object schemas, structural final decoders and
  typed nonterminal views from core StructuredModel/StructuredField annotations.
- Use existing runtime schema/decoder/snapshot APIs, with source diagnostics for
  unsupported types, construction, guides, cycles, depth and expanded bounds.
- Preserve required/nullable choices, exact scalar/enum conversion and safe partial
  prefixes; no inference, generated Swift, routing or business validation.
- Add builder contracts, compiled example outputs and a separate 100% line gate.
